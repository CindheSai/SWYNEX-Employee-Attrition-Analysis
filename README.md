# Employee Attrition Analysis and Data Preprocessing

## Project Overview
This project explores employee attrition data using Python and data analysis techniques as part of the SWYNEX Technologies Machine Learning Internship.

## Objectives
- Explore the dataset structure and feature distributions.
- Inspect missing values, duplicate records, and constant columns.
- Analyze employee attrition patterns across departments, job roles, and overtime status.
- Visualize important findings using Matplotlib and Seaborn.
- Prepare a reliable preprocessing workflow for machine learning.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab

## Dataset
IBM HR Analytics Employee Attrition & Performance dataset.

Dataset source: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

Please review the dataset's applicable license and usage conditions.

## Project Workflow
1. Data loading and inspection
2. Data quality assessment
3. Exploratory data analysis
4. Attrition distribution and categorical analysis
5. Data cleaning and preprocessing
6. Train/test preparation and validation

## How to Run
1. Open the notebook in Google Colab.
2. Upload the dataset CSV when prompted.
3. Run the notebook cells in order.
